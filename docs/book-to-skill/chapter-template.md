# 章节生成规范（book-to-skill · technical · study 深度）

你要把一份中文 C++ 知识库主题页，转换成一个**章节文件**（`chapters/chNN-<slug>.md`）。

## 硬性规则

1. **提取结构，不写摘要**。产出的是「工具箱」：命名过的框架、可执行的规则、操作步骤、反模式。
   不是读书报告。保留原文的精确措辞——框架名、规则号、术语不要改写、不要"润色"。
2. **绝不复制原文长段**。综合、改写、提炼信号。单段引用不超过 2 行；代码片段可以照抄
   （代码是工具不是版权表达），但要保留缩进，并只挑最能说明问题的那一段。
3. **规则号必须准确**。C++ Core Guidelines 规则号（如 `R.11`、`CP.20`、`ES.31`、`Per.1`）
   必须真实存在。白名单在 `knowlege/_meta/core-guidelines-rules.txt`（500 条，格式 `R.11: "标题"`）。
   引用前先核对该文件里确实有这一条。**不确定的规则号就不要写**——写错比不写更糟。
   注意：并发规则是 `CP.*`，性能是 `Per.*`，所有权是 `R.*`，宏/语句是 `ES.*`，
   类是 `C.*`，函数是 `F.*`，错误处理是 `E.*`，模板是 `T.*`。
4. **中文输出**。术语第一次出现时给中英对照（例如「移动语义（move semantics）」）。
5. **不写空章节**。如果某节内容确实没有（比如没有反模式），省略该节，不要凑数。
6. **每个结论可追溯**：给结论时带上 Core Guidelines 规则号或原文出处链接。

## 章节文件结构（严格按此顺序，用这些二级标题）

```markdown
# Chapter N: <中文标题>（<English Title>）

## Core Idea
<1–2 句：这章最核心的一件事。用祈使句/判断句，不要"本章介绍了…">

## Frameworks Introduced
- **<框架/规则名>**：<精确表述——保留作者的命名>
  - When to use: <具体场景>
  - How: <步骤或判据>
（3–6 条）

## Key Concepts
- **<术语>**：<一句话精确定义>
（5–10 条，本章最重要的术语）

## Mental Models
<2–4 个思维工具。写成「用 X 当 Y 时」或「把 X 想成 Y」>

## Anti-patterns
- **<要避免什么>**：<为什么失败>

## Code Examples
<!-- 照抄最能说明问题的片段，保留缩进 -->
```cpp
<代码>
```
- **What it demonstrates**: <一行>

## Reference Tables
<!-- 把原文里的对比矩阵/决策表复现成 markdown 表格 -->

## Worked Example
<一个具体、完整、可照着做的例子（代码或决策过程）。这是读者真正会回来看的部分。
 要能独立看懂：给上下文、给步骤、给结果。>

## Key Takeaways
1. <可执行的洞察>
（3–7 条）

## Connects To
- **Ch N**: <为什么相关>
- **<概念>**: <关联的标准/其它章节概念>
```

## 技术细节

- 每个章节文件 **2000–3000 tokens**（technical + study）。密度优先，不要注水凑字数。
  如果某章天然很薄，就让它薄，并**不要**加无信息量的段落。
- 代码示例至少 1 个；原文有反例（✗）时，反例比正例更值得放进 Worked Example。
- Reference Tables：原文有决策表/对比表就复现；没有就省略这一节。
- `Ch N` 的交叉引用用章节编号（Ch01..Ch15），不要用文件名。

## 完成后在回复里附上「抽取卡」

文件写完后，在最终回复里**只**输出下面这段抽取卡（用于我汇总 glossary/patterns/cheatsheet），
不要重复章节内容：

```
### EXTRACT chNN
TERMS: 术语一 | 术语二 | 术语三 | 术语四 | 术语五
PATTERNS: 模式一（何时用一句话；做法一句话） | 模式二（...） | 模式三（...）
DECISIONS: 当 X 时选 Y，因为 Z | 当 A 时不要做 B，因为 C
TABLE: 用一句话描述本章最值得做成决策表的对比（列 vs 行）
```

TERMS 每项用 `名（English）` 形式；PATTERNS 最多 3 条；DECISIONS 最多 3 条。
