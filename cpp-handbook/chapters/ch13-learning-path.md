# Chapter 13: 学习路线（Learning Path）

## Core Idea
四阶段递进，每一阶段都以**能读懂、能写出、能改对**为目标，不以"看完"为目标；
每阶段末尾都有"检验你是否真的会了"的自查题——**没通过自查就别进下一阶段**。

## Frameworks Introduced
- **能力目标而非阅读量**：阶段目标写成"能做什么"，不是"读多少"。
  **When to use**：任何学习计划的自我评估。**How**：把目标改写成可证伪的动作
  （"能写出正确使用 `std::forward` 的转发函数"而不是"理解完美转发"）。
- **阶段门禁（Gate）**：每阶段末尾一组自查题，答不上来就回去补。
  **When to use**：防止"读过就以为会了"。**How**：把阶段 0 的题当阶段 1 的入学考试。
- **案例驱动贯穿全程**：无论哪个阶段，都同时在做案例驱动的练习。
  **When to use**：学任何阶段。**How**：每天一道 LeetCode + 每周重写一个经典算法。
- **材料按需翻而非通读**：速查表类材料当字典，教程类材料系统过一遍，标准类材料查着读。
  **When to use**：选材料时。**How**：先问"我要解决的是'记不住'还是'不理解'"——
  前者翻速查表，后者读教程。

## Key Concepts
- **阶段 0 · 语法与心智模型**：把陌生 C++ 代码读明白，知道每个声明背后的资源语义
- **阶段 1 · 现代 C++ 语法**：用 C++17/20 的写法，而不是"带新语法的 C++98"
- **阶段 2 · 工程与质量**：代码能被接手，也能在别人机器上跑起来
- **阶段 3 · 深入与性能**：能定位并解决真实的性能与并发问题
- **必看主题页**：每个阶段点名要读的章节，是该阶段的最小充分集合
- **自查题（Self-check）**：阶段门禁用的可证伪问题
- **时间投入参考**：每日投入 × 周期 → 产出能力的估算

## Mental Models
- **爬楼梯而不是走平路**：阶段 0 的心智模型是阶段 1 的地基。
  跳过阶段 0 直接学移动语义，学到的是语法不是语义。
- **把"读"换成"写"**：一个概念的掌握度 ≈ 你能在空白编辑器里写出它的次数。
- **快查表是急救包不是教材**：速查表用来在写代码时三秒查到签名，不是用来通读的。

## Anti-patterns
- **以"看完"为目标**：看完 12 章教程不等于能写出可交付的代码。
- **只读不敲**：learncpp 的每一章代码都手敲一遍，是因为读代码和写代码暴露的问题不同。
- **跳过自查题**：自查题答不上来，说明这一阶段的"必看主题页"没吃透。
- **按题号刷 LeetCode**：从 1 刷到 4000 是体力活；按题型标签刷才是能力建设。
- **在阶段 0 之前碰并发**：并发需要阶段 0 的资源语义做底，否则会把数据竞争误读成"玄学 bug"。

## Code Examples
阶段 0 的自查题样例——指出下面代码的问题：

```cpp
std::vector<int> v;
for (int i = 0; i <= v.size(); ++i) { /* ... */ }   // 越界 + 有符号/无符号
```

两个问题：`i <= v.size()` 在 `v` 为空时就会越界（`size()` 返回 0，`i` 从 0 开始）；
`i` 是 `int` 而 `size()` 返回 `size_t`，比较时 `int` 会被提升成无符号，
负数会变成巨大的正数。正确写法是 `std::size_t i = 0; i < v.size(); ++i`。

## Worked Example
**一个 30 天的入门排期（阶段 0 + 阶段 1 起步）。**

| 天 | 做什么 | 产出 |
|---|---|---|
| 第 1–3 天 | learncpp Basics 每章手敲 | 能读懂基础语法 |
| 第 4–5 天 | 词汇表过一遍，Core Guidelines Intro | 建立"规则"意识 |
| 第 6–7 天 | 读 Ch11 陷阱与反模式；过阶段 0 的自查题 | **门禁：不通过就重复上面三天** |
| 第 8–14 天 | learncpp 继续（Functions/Lambdas/Pointers）；每天一道 LeetCode 对照 `08-leetcode-cases` | 阶段 0 能力稳定 |
| 第 15–28 天 | `04-modern-cpp-tutorial` zh-cn 第 2/4/7 章（usability / containers / thread）；`06-modern-cpp-features` 当字典翻 | 阶段 1 主体 |
| 第 15–28 天（并行） | 读 Ch01 所有权 + Ch02 移动语义 + Ch03 模板 + Ch04 STL | 主题页与教程互相对照 |
| 第 29–30 天 | 过阶段 1 的四道自查题 | **门禁** |

关键点：第 7 天和第 30 天是**硬门禁**——不通过就不前进。
如果第 30 天答不出"为什么移动构造要标 `noexcept`"，就回去重读 Ch02 的
"移动操作必须 noexcept"一节，而不是继续往后赶。

## Key Takeaways
1. 目标写成"能做什么"，不写成"看多少"。
2. 每阶段末尾有门禁，答不上来就补，别硬推。
3. learncpp 的代码要手敲一遍——读和写暴露的问题不一样。
4. 速查表当字典翻，教程系统读，标准查着读；先判断你要解决的是"记不住"还是"不理解"。
5. 案例驱动贯穿全程：每天一道 LeetCode，每周重写一个经典算法。
6. 并发必须放在阶段 0 之后——没有资源语义做底，数据竞争会变成玄学。
